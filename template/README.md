# template/

Modelli pronti da usare per ogni tipo di contenuto. Ogni template ha:

1. **Struttura** – le sezioni da compilare;
2. **Istruzioni** – brevi regole pratiche;
3. **Esempio fittizio** – per capire il risultato atteso (non va mai pubblicato così com'è).

| File | Per cosa |
|---|---|
| [`post-linkedin.md`](post-linkedin.md) | Post LinkedIn aziendali o personali |
| [`newsletter.md`](newsletter.md) | Newsletter via email |
| [`script-tiktok.md`](script-tiktok.md) | Video verticali brevi (TikTok, Reels, Shorts) |
| [`scaletta-podcast.md`](scaletta-podcast.md) | Puntate del podcast |
| [`scheda-lezione.md`](scheda-lezione.md) | Video di formazione |
| [`brief-campagna.md`](brief-campagna.md) | Brief di una campagna con obiettivi e KPI |

## Come usarla

- **Non modificare i template per un singolo contenuto**: copia la struttura nel nuovo file o chiedi a Claude di usarla.
- Chiedi sempre a Claude di usare il template **insieme a** `brand/linee-guida.md` e `brand/glossario.md`.
- Se un template non funziona più, migliora il template stesso con una pull request: il miglioramento varrà per tutti i contenuti futuri.
- Dopo la pubblicazione, registra il contenuto in `contenuti/archivio.md`.
