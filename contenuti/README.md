# contenuti/

L'archivio di tutto ciò che pubblichiamo, su ogni canale, con i risultati.

| File | Contenuto |
|---|---|
| [`archivio.md`](archivio.md) | Tabella di tutti i contenuti pubblicati |

## Come usarla

- **Dopo ogni pubblicazione** aggiungi una riga in `archivio.md` (in alto le più recenti).
- Dopo 7-30 giorni torna sulla riga e completa le **note sui risultati**.
- Chiedi a Claude di leggere l'archivio prima di proporre nuovi argomenti, per evitare ripetizioni e ripartire da ciò che ha funzionato.
- Se un contenuto ha un testo lungo da conservare (script, scaletta), puoi creare un file in questa cartella, es. `contenuti/2026/2026-11-05-linkedin-checkout.md`, e collegarlo dalla tabella.
