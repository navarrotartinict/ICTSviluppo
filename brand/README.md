## Come usarla

- **Indica sempre questi due file a Claude** quando chiedi un contenuto: sono la base per ottenere testi coerenti.
- Compila per primi i segnaposto `[DA COMPILARE: ...]` di `linee-guida.md`: senza quelli, ogni contenuto resta generico.
- Quando nasce una nuova regola ("non diciamo più X, diciamo Y"), aggiungila qui con una pull request, così vale per tutti da quel momento in poi.
